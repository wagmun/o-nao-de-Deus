# Site do livro *O Não de Deus é o Espaço para Nossa Liberdade*

Página estática bilíngue (PT / EN), sem dependências: `index.html`, `styles.css`, `script.js` e a pasta `assets/` (capas).

## Publicação

GitHub Pages, conta `wagmun`. Só sobem esses arquivos; manuscritos, PDFs, PNGs grandes e materiais da Amazon ficam fora (veja `.gitignore`).

## Captura de e-mail

Formspree (plano gratuito). O endereço do formulário fica na constante `FORM_ENDPOINT`, no topo do `script.js`. Os e-mails cadastrados aparecem no painel do Formspree, com o idioma e a rede de origem.
