# Site Oficial — *O Não de Deus é o Espaço para Nossa Liberdade*

Página estática minimalista, bilíngue (**PT / EN**) e sem dependências, criada com a paleta visual da capa do livro (`#091422` azul-marinho profundo + `#D4AF37` dourado).

## Como Publicar de Graça em 2 Minutos

Não precisa de build nem servidor — basta subir os 3 arquivos (`index.html`, `styles.css`, `script.js`):

- **GitHub Pages:** Crie um repositório, suba os arquivos e ative **Settings → Pages → Branch `main`**.
- **Cloudflare Pages ou Vercel:** Arraste a pasta ou conecte o repositório Git (deploy gratuito e HTTPS automático).
